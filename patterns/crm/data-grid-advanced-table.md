**Structure:**
```
[Data grid]
  ├── [Toolbar: column config, filters, export, search]
  ├── [Pinned header row]
  ├── [Data rows with inline editing]
  │     ├── Row selection checkbox
  │     ├── Pinned columns (left)
  │     ├── Scrollable columns
  │     └── Row action kebab
  ├── [Column resize handles]

```
